# myData

Open-source, self-hosted personal cloud with a local assistant. All data stays on hardware you own.

- `host/`: the host (Python): the `mydatad` service, the tool layer, the HTTP API and MCP server, the orchestrator, and the feasibility harness. See `host/README.md`.
- `app/`: the Flutter app (coming in phase 2).
- `CLAUDE.md`: the project's working memory: the rules, decisions and status in force. History and results are in `docs/decisions/` and `host/results/`.
