# myContacts

The contacts app. It shows the contacts the host mirrors from its sources (This Mac, an iCloud account), which stay read-only, and the contacts the host owns, which it creates, edits and deletes: "New contact" (⌘N), Edit (⌘E) in an Inspector in the contact pane's place (the editor sheet on a phone), Delete (⌘⌫) to Recently deleted with an Undo toast, several at once with a Dialog, Undo in the menu bar named from the action, and a Recently deleted section (restore, or delete for good). It can start the host but never stops it. It opens `mycontacts://contact/<id>` links and remembers the contact last opened on this device. See `../../README.md`.
