A place on a page that takes files dropped from the Finder or Explorer, with a button that opens the system's file chooser for the same thing. It reads the files and says what it found, or why it could not.

**Status: decided 2026-10-14** (phase 4; the owner's review of ImportFlow, whose Decisions it follows).

- **Use it for** bringing a file into myData: contacts (one `.vcf` or `.zip`) on the Import page (ImportFlow); later calendars (`.ics`, phase 6) and the contact photo picker (a single image, phase 3's follow-up).
- **Not for:** attaching files to a message (myMail gets its own attachment field), or choosing a folder.
- **Anatomy.** A `surface-sunken` well on `bg` with `radius-lg`, as wide as the reading column, `space-8` padding down and `space-6` across, its content centred:
  - an `icon-tile` with an outline "tray with an arrow" icon, `accent` on `accent-soft`;
  - `space-3` under it, the instruction in `body-strong` and `ink`: "Drop a .vcf or .zip file here";
  - `space-1` under it, the caption in `caption` and `ink-muted` saying what it takes and the size limit: "A vCard file (.vcf) from Apple, Google or Samsung, or a .zip of them. Up to 50 MB." (the host's cap: 50 MB uploaded, 200 MB once a zip is unpacked);
  - `space-4` under it, the button "Choose file…" (Filled where it is the page's main action, as on Import's Choose step; Tonal elsewhere). It opens the system's own file chooser (platforms.md), filtered to the types the zone takes. It takes one file: the host reads one input per import, and several files go in one .zip (ImportFlow, Decisions, 5).
  - No border and no dashed line: the sunken well is the shape, as Notice and the text wells are. It is not a card, so it can sit in a page beside cards without being a card on a card.
- **Where it takes a drop.** While files are dragged over the window, the whole page the zone is on accepts them, and the zone shows that it will take them, so a drop a little off target is not lost. Other pages and other apps' windows are not changed.
- **States.**
  - **Idle:** as above.
  - **Dragging over the page:** the well's fill becomes `accent-soft`, with a 2px `accent` line drawn inside its edge, over `fast`. The instruction changes to "Drop to import contacts-2026-10-14.vcf" (the file's name when the platform gives it before the drop, else "Drop to import"), so the state never relies on colour (Graphite's `accent-soft` is grey). Which files the zone takes is checked after the drop, not while dragging: the platforms do not all say what is being dragged before it lands.
  - **Reading:** the icon tile is replaced by the loading slice (the kiwi loader), the instruction by "Reading contacts-2026-10-14.vcf…", the caption by "A large file takes up to half a minute.", and the button by "Cancel" (plain). The host reports no progress (about 20 s for 44,000 cards), so there is no figure. Cancel returns to Idle at once; nothing has been written. The host cannot be stopped mid-read, so it finishes and holds a preview: when its answer arrives, the app discards it (`DELETE /import/previews/{id}`), so the file's contents are not held for the hour.
  - **Error:** the zone returns to Idle, with the caption replaced by the error in `danger`, in `body`, as a sentence that names the file, says what is wrong and gives one next step (ImportFlow, "States"). The tile's icon becomes the `warning` outline on `warning-soft`. Focus goes to "Choose file…" (or to "Try again", tonal, beside it, when the host did not answer: it sends the same file). The error stays until the next drop or choice.
  - **Disabled** (the host cannot be reached): the tile, instruction and button at 45% opacity; the caption, in full `ink-muted`, is the reason: "The host cannot be reached. Import works when it is running." The button leaves the Tab order, because its reason is visible (platforms.md, "Disabled controls"). Drops are refused, and the zone does not light up.
  - Hover and pressed belong to the button. The well has none.
- **Several files** dropped at once are refused before anything is sent: "Drop one file at a time. To bring several, put them in one .zip." (ImportFlow, Decisions, 5.)
- **Checked before sending, by extension:** `.ics` (a calendar), `.csv`, and anything not `.vcf` or `.zip` get their own sentence (ImportFlow, "States"), so the user learns what the file is, not only that the host found no vCard. Everything else is decided by the host: a refusal (400) carries one sentence, shown after the file's name, and a next step (ImportFlow, "States"; each case has a `code`, H4, built).
- **Folders** dropped on the zone are not opened: "Contacts is a folder. Drop the file in it instead."
- **Keyboard.** The well is not a stop; its button is. ⌘V (Ctrl+V) with a file on the clipboard, while the page has focus and no text field does, is the same as a drop. After an error, focus is on the button; after reading, focus moves to the next step's title (ImportFlow).
- **Screen readers.** The well is a group named by its instruction, described by its caption. A drop and its outcome are announced: "Reading contacts-2026-10-14.vcf" (polite), then the next step's title, or the error (assertive, because it answers the user's own action). Dropping is a pointer action; the button does everything a drop does, so no one needs to drag.
- **Motion.** The fill and the inner line fade over `fast` with the `standard` curve. Nothing moves. Reduced motion changes nothing; the loading slice does not turn (motion.md).
- **Light and dark, every theme:** only tokens. In dark mode `surface-sunken` is darker than `bg`, so the well reads as a hollow in both modes. The dragging state's word does the work in Graphite, where `accent-soft` is grey.
- **Under 600px (phones).** There is nothing to drop from. The well keeps its shape, without the instruction: the tile, the caption and the button "Choose file…", which opens the system's picker (Files on iOS; the system picker on Android). Reading and errors are the same.
- **Sizes.** One. The button is `control-height`.
- **Copy.** The instruction names the file types the user knows ("Drop a .vcf or .zip file here"). The caption names where such files come from and the size limit. Errors and reasons are sentences with full stops. The button is "Choose file…", with the ellipsis because it opens a chooser (platforms.md); "Choose files…" only where several are taken.
- **Token:** none new. It uses `surface-sunken`, `accent-soft`, `accent`, `radius-lg`, `icon-tile` and the spacing scale.
- **For implementers:** `desktop_drop` for the drop and `file_selector` for the chooser (pub.dev; macOS, Windows, Linux); the apps are not sandboxed today, so no file-access entitlement is needed. Files go to the host as bytes, never as paths (plan 3.5): `POST /import/contacts/preview?filename=` with the body as it is; the file's name is only a label. Read the file, check its size (50 MB) and extension before sending; 413 is the host's own size refusal.
- You provide the instruction, the caption, the file types, whether several are allowed, and what happens with the file.
