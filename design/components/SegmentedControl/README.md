A pill-shaped set of two to five mutually exclusive options that switch or filter the view below it.

- The track is `surface-sunken` with `radius-pill` and no border.
- The selected segment is a `surface` pill with `shadow-1` and `ink` text; the others are `ink-muted`.
- The selected pill slides to its new position with the `spring` motion.
- For more than five options use a menu.
- You provide the options and which one is selected.
