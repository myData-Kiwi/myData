A round button with only an icon, for a frequent action whose icon people already know. A tooltip and an accessible name say what it does.

- **Use it** where a row or a bar has no room for a label and the icon is familiar: previous and next month, copy a value, remove a field from a form, new item in a title bar, flag a message.
- **Do not use it** for a screen's main action (a filled Button, with words), for an action people would have to guess from the icon (a Button with a label), for a choice between options (SegmentedControl), or to open a list of several actions (a Menu), except the "More actions" button, which opens a Menu (announced as having a pop-up menu; Menu). If a label fits, use a Button. Never use it to delete a saved record with no Undo.

- **Anatomy:** a `control-height` square target with `radius-pill`, so the button is a circle. One outline icon at `icon` size with the 1.75px stroke, centred. No border, and no fill at rest.
- **Tones:**
  - **Default:** the icon in `ink`. Bars, title bars and navigation, such as MonthGrid's previous and next.
  - **Quiet:** the icon in `ink-muted`, for a secondary action at the end of a row whose value must stay the loudest thing, such as FieldRow's copy button.
  - **Danger:** the icon in `danger`, only for removing one value from a form that has not been saved (a phone number in the contact editor). Cancel brings it back, so it never asks first. Deleting a saved record with an Undo uses the default tone: a red icon in every toolbar would be loud for an action that can be undone. Its focus ring is `ink`, not the red `focus`, so it never merges with the red icon and its `danger-soft` hover (design/README.md, "Focus and danger").
- **States:**
  - Hover: the circle fills with `surface-hover` (`danger-soft` in the danger tone), appearing and going with `fast`. The pointer and the tooltip are the other signs.
  - Pressed: the shared press. The button dims to 85% and scales to 97% at once, and returns over `fast`.
  - Focused: the 2px `focus` ring, 2px outside the circle, when focus came from the keyboard. Keyboard focus also shows the tooltip.
  - Disabled: the icon at 45% opacity, and pressing it does nothing. Its reason is only in its tooltip, so it **stays focusable** (announced as dimmed or unavailable), by the system rule in platforms.md ("Disabled controls"): Tab reaches it, and focus shows the tooltip with the reason on a second line in full `ink-muted` ("The host cannot be reached."), which screen readers hear as the hint. Hover shows the same tooltip. A button is never disabled without a reason. `Pressable`, which today takes disabled controls out of focus, needs a mode for this.
  - **Toggled on** (only for a button that switches a state on a record, such as Flag): the circle fills with `accent-soft`, the icon turns `accent`, and the icon changes from its outline form to its filled form (an outline flag becomes a filled flag). The filled glyph carries the state. In Graphite in light mode `accent-soft` is close to `surface-sunken`, so the fill alone would not show it (the same reason MonthGrid's ring carries selection). Hovering a toggled button keeps its fill. The danger tone has no toggled state.
  - **Done** (only for a one-shot result shown in place, such as FieldRow's copy): the icon becomes a check and the tooltip becomes the result word ("Copied") until something else happens. The check keeps the button's tone. It is never green, so it cannot be read as a success status without words.
- **Tooltip:** `surface-raised`, `radius-sm`, `shadow-2`, the text in `caption` and `ink`, with `space-1` padding above and below and `space-2` across. It sits `space-1` below the button, or above it when there is no room below. It appears after the platform's hover delay, or at once on keyboard focus, and fades in over `fast`. Escape hides it. It holds the accessible name exactly. When the action has a shortcut, the shortcut follows in `ink-muted`: "New event ⌘N".
- **The accessible name is required.** It uses the same words as the tooltip: a verb and its object ("Copy work email", "Remove mobile number"), or the destination for navigation ("Previous month", as MonthGrid already names it). When several buttons on one screen share an icon, each name says which item it acts on ("Remove mobile number", "Remove home number"). A toggled button keeps one name ("Flag") and is announced as a toggle button that is on or off. Its name never switches to "Unflag".
- **Keyboard:** Tab reaches it, and Return and Space press it. Each button is its own tab stop: there is no toolbar spec yet that would group them.
- **Motion:** the hover and toggled fills change over `fast`; the press is the shared one. With reduced motion the press does not scale and the fills only fade.
- **Light and dark, Kiwi and Graphite:** colours come only from tokens. The toggled state is readable in Graphite because of the filled glyph. The hover fill, `surface-hover`, shows on `bg`, `surface` and `surface-raised` in both modes (see Token). The tooltip's `surface-raised` is lighter than `surface` in dark mode, so it separates without relying on its shadow.
- **Desktop and phone:** on desktop, as above. Phones have no hover, so there is no hover fill and no tooltip on hover. The accessible name is the same. On Android a long press shows the tooltip, as the platform does. On iPhone nothing extra is shown. The target stays 44px.
- **Sizes:** one size, `control-height` (44px). In the Compact density on desktop the target is `control-height-compact` (36px), as for every control in Compact. The icon is always `icon` size.
- **Copy:** the tooltip and name are in sentence case, with no full stop. Never "Click to…", and never the icon's own name ("Trash icon"). A disabled button's reason is a full sentence and takes a full stop, as reasons do everywhere (platforms.md, "Disabled controls").
- **Existing ad hoc icon buttons this replaces:** MonthGrid's previous and next buttons (default tone; they gain the hover fill and the tooltip, which they lack today) and FieldRow's copy button (quiet tone, done state; unchanged).
- **Token:** `surface-hover` (tokens.json), the neutral hover and highlight fill. `surface-sunken` barely showed anywhere (against `bg` 1.08:1 in light mode and 1.04:1 in dark; against `surface-raised` 1.17:1 and 1.25:1), so a hovered button in a title bar and the pointer's highlight in a menu were nearly invisible. `surface-hover` is #D9D9D6 in light mode (1.41:1 on `surface` and `surface-raised`, 1.31:1 on `bg`) and #383838 in dark (1.48:1 on `surface`, 1.34:1 on `surface-raised`, 1.61:1 on `bg`). Hover is never the only signal (the pointer and the tooltip are), so it need not reach 3:1. It serves IconButton's hover, the Menu and Select highlight, the Select field's hover, the Checkbox's hover and the GroupedList row hover.

- **Used by:**
  - myCalendar month view: "Previous month" and "Next month" (exists).
  - myContacts contact page: the copy button of each FieldRow, quiet tone with the done state (exists).
  - myContacts edit contact: "Remove mobile number" at the end of each phone, email and address row, danger tone (phase 3).
  - myContacts and myCalendar title bars: "New contact" and "New event", a plus icon with ⌘N in the tooltip. On a phone they are the only way to add, because there is no menu bar (phases 3 and 6).
  - DatePicker popover: "Previous month" and "Next month" (phase 6).
  - myMail message bar: "Flag" (toggled), "Move to Trash" and "Reply" (phases 5 and 7).
  - "More actions" (three dots), the one IconButton that opens a Menu: beside Edit on myContacts' contact pane, in the header of a record's screen on a phone, and at the end of a calendar's row in myCalendar's calendar list (phases 3 and 6; Menu).
- **Decided 2026-10-14:** the hover fill is the new `surface-hover`; the "More actions" IconButton is the one exception allowed to open a Menu; a disabled IconButton stays focusable (Pressable's focusable-but-inert mode); the danger tone's focus ring is `ink`.
