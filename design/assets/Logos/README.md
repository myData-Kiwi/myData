# Logos

The kiwi mark: a hand-drawn kiwi bird in ink over a green wash.

| File | Use |
|---|---|
| `mydata-kiwi-mark.svg` | The mark with its green wash. Empty screens, first-run and the website, always on a `paper` tile inside the apps |
| `mydata-kiwi-mark-mono.svg` | Ink outline only, where one colour is required |
| `mydata-kiwi-logo-square.svg` | The mark on a pale green square. Profile pictures |
| `mydata-kiwi-app-icon.svg` | The first app icon, superseded by `app-icons/` |
| `app-icons/` | The four apps' icons (see its README) |

Rules:

- The ink in these files is a fixed dark colour. Place the mark on `paper`, which stays light in both themes. A light-ink version does not exist yet.
- Do not recolour, redraw or straighten the mark, and do not tint it with the user's accent.
- myData's app icon is green in every theme and appearance. The other apps' icons have their own colours and glyphs, with no kiwi (`app-icons/README.md`).
- myData's icon uses the mark without the logo's ground line.
